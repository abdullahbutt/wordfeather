5. Schreiben

Feste Struktur / Fixed structure

  1. [Ort], den 12. Dezember 2026 (use the real date and your own city)
  2. Liebe / Lieber [Name], (two names: Liebe Marie, lieber Lukas)
  3. vielen Dank für deinen Brief / deine E-Mail. Ich habe mich sehr gefreut. + one reaction sentence
  4. Point 1 (2–3 sentences) · Point 2 · Point 3 · Point 4, in the order of the task
  5. Ich freue mich schon auf deine Antwort / auf unser Treffen.
  6. Viele Grüße / Herzliche Grüße, [your name]
  • Answer all 4 points, one short paragraph each. Missing a point costs more than a grammar error.
  • Aim for about 100 words and count them in practice.
  • Use sentences you control. Short and correct beats long and wrong.
  • Two recipients: use ihr / euch / eure and both names in the greeting.
  • Never copy a model answer. The task changes, so adapt the four points.

Bewertung (offizielle Kriterien) / How it is marked

CriterionWhat counts
AufgabenbewältigungAll 4 points covered, appropriate content and length
Kommunikative GestaltungGreeting, opening, closing, clear order, connected sentences
Formale RichtigkeitGrammar, spelling, vocabulary. Only one of three criteria.

6. Sprachbausteine

Im Text stehtLücke meistWarum
Text has: schade, informieren, glauben, schreiben + commadassSubordinate clause, verb at the end.
wissen, Frage ist, interessiert michobIndirect yes/no question.
Ich … noch / wenn ich …hätte / wäre / würdeKonjunktiv II (politeness, wish).
Wir Ihnen dankbarwärenKonjunktiv II of sein.
Bitte/request with Sie as subjectkönnten / würdenPolite request.
trotz, wegen, während, stattGenitiv (des / der)Genitive prepositions.
an etwas … sein / für diesen Job …interessiert / geeignetFixed verb + preposition pairs.
Wochen / Tage / Jahre after the gappaar / einigeQuantity words.
…liebsten · …Voraus · so schnell … möglicham · im · wieFixed 2-word phrases.
Mit … Grüßen · Vielen … · zum …freundlichen · Dank · BeispielLetter set phrases.

Frag dich der Reihe nach / Ask in this order:

  • 1. Have you seen this exact phrase before (fixed phrase)? Write it from memory.
  • 2. Is there a preposition right before the gap? Apply that preposition and its case.
  • 3. Does the verb go to the end after a comma? Then it is a conjunction (dass, weil, wenn, ob, damit).
  • 4. Only if none of these fits: guess from meaning.
The cheat sheet says some letters repeat across papers and the answers stay the same. That may happen, but you cannot rely on it. Use it as a bonus, and learn the grammar rules above.

7. Sprechen, Lesen, Hören

Sprechen Teil 2: 2–3 Minuten pro Thema

  1. Introduce: "Es geht um das Thema …"
  2. Person A: what they say, in your own words (use sie / er meint, dass …).
  3. Person B: the same, then compare the two in one sentence.
  4. Your opinion with one reason: "Ich finde …, weil …"
  5. Your experience or home country: "In meinem Heimatland …"
  6. Close: one sentence, then be ready for a question from the examiner or partner.

Lesen & Hören

  • Lesen Teil 1: read all headlines first, match keywords. Headlines can sound alike, so check the details.
  • Lesen Teil 2: questions follow the text order. The answer is usually paraphrased, not literal.
  • Lesen Teil 3: decide richtig / falsch from the ad. If it is not in the ad, it is falsch.
  • Hören: read the questions during the pause, write short notes, never stay on a missed item.
  • Fill every answer. There is no penalty for a guess.

8. Phrasen / Phrase bank

Persönlicher Brief – Anrede / Einleitung
  • Liebe Claudia, / Lieber Tobias, / Hallo Claudia,
  • Vielen Dank für deinen Brief. Ich habe mich sehr gefreut.
  • Schön, etwas von dir zu hören. Es ist schon lange her, dass wir …
  • Wie geht es dir? Mir geht es gut, / leider nicht so gut, weil …
  • Endlich habe ich Zeit, dir zu schreiben.
Persönlicher Brief – Schluss
  • Lass bald wieder von dir hören. / Schreib mir bald.
  • Es wäre schön, wenn du kommen könntest.
  • Ich freue mich schon auf deine Antwort / auf unser Treffen.
  • Viele / Liebe / Herzliche Grüße · Bis bald
Halbformeller Brief
  • Sehr geehrte Frau Schneider, / Sehr geehrter Herr Schneider, / Sehr geehrte Damen und Herren,
  • Vielen Dank für Ihren Brief vom 2. Februar. Sie schreiben, dass …
  • Ich wäre Ihnen dankbar, wenn Sie mir … schicken könnten.
  • Könnten Sie mir mitteilen, …? / Wäre es möglich, …?
  • Vielen Dank im Voraus. / Über eine baldige Antwort würde ich mich freuen.
  • Mit freundlichen Grüßen
Reaktion und Tipps (Schreiben)
  • Das freut mich sehr für dich! / Herzlichen Glückwunsch!
  • Das tut mir leid. Das ist wirklich nicht einfach.
  • Ich finde, du solltest … / Mein Tipp: … / Du könntest …
  • Das ist eine super Idee! Ich komme gern mit.
  • Was meinst du? / Ist das okay für dich?
Sprechen Teil 1
  • Mein Name ist … Ich komme aus … Ich bin in … geboren.
  • Seit … Jahren lebe ich in … Ich wohne mit … zusammen.
  • Ich arbeite als … / Ich studiere … / Ich mache eine Ausbildung als …
  • Meine Muttersprache ist … Außerdem spreche ich … und Deutsch.
  • Ich habe in / an … Deutsch gelernt. Ich lerne seit … Monaten.
  • In meiner Freizeit … Mein Hobby ist …, weil …
  • Questions to your partner: Woher kommst du? Wie wohnst du? Hast du Geschwister? Wo hast du Deutsch gelernt? Was machst du beruflich? Welche Sprachen sprichst du?
Sprechen Teil 2
  • Es geht um das Thema … / Das Thema ist …
  • Auf meinem Aufgabenblatt sagt eine Frau / ein Mann, dass …
  • Sie / Er meint, dass … Außerdem sagt sie / er …
  • Diese Meinung finde ich interessant, weil … / Ich finde es (nicht) richtig, dass …
  • Ich habe die Erfahrung gemacht, dass …
  • In meinem Heimatland ist es wichtig, dass … / Bei uns ist das ganz ähnlich / anders, denn …
Sprechen Teil 3 / Diskussion
  • Ich denke / glaube / finde, dass … · Meiner Meinung nach …
  • Ich sehe einen Vorteil / Nachteil darin, dass …
  • Ich sehe das auch so. / Nein, das denke ich nicht. / Ich verstehe das, aber …
  • Kannst du das noch einmal erklären? / Weißt du, ob …?
  • Wie wäre es, wenn wir …? / Ich schlage vor, dass wir …
  • Entschuldige, darf ich dazu etwas sagen? / Moment, ich muss kurz überlegen.
